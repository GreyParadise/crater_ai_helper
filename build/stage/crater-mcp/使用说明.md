# Crater MCP 离线包

版本 0.1.0 · 构建日 20261109 · 只需 **Node.js 20+**（依赖已随包附带，**不需要外网、不需要 npm install**）

## 1. 解压 + 填配置

```bash
unzip crater-mcp.zip && cd crater-mcp
cp .env.example .env       # 改下面三项
```

```ini
CRATER_BASE_URL=http://172.16.16.140
CRATER_USERNAME=你的平台用户名
CRATER_PASSWORD=你的平台密码
CRATER_TOOL_GROUPS=auth,profile,jobs,files,images,resources,stats,datasets,cli,feedback
```

## 2. 自检（能打印身份就说明通了）

```bash
node dist/index.js --whoami
node dist/index.js --check
node dist/index.js --list
```

Windows 可用 `run.cmd --whoami`；Linux/macOS 用 `./run.sh --whoami`。

## 3. 接到 agent（以 MCP 客户端通用配置为例）

```json
{
  "mcpServers": {
    "crater": {
      "command": "node",
      "args": ["/绝对路径/crater-mcp/dist/index.js"],
      "env": { "CRATER_ENV_FILE": "/绝对路径/crater-mcp/.env" }
    }
  }
}
```
